# User Flows

## Flow 1: Quick Capture

Thought → Open app → Type title → Enter → Saved to Inbox

```text
1. User has a thought
2. Opens app (or Ctrl+Space on desktop)
3. Types title
4. Presses Enter
5. Item created in Inbox (area_id = NULL)
```

## Flow 2: Process Inbox

```text
1. Open Inbox
2. Select item
3. Assign Area
4. Assign Type
5. Save
6. Item leaves Inbox
```

## Flow 3: Complete Task

```text
1. Open Today
2. Mark Done
3. Task disappears from Today
```

## Flow 4: Create Child Items

```text
1. Open parent item
2. Add child
3. Nest items under it
```

## Flow 5: Search

```text
1. Type query
2. Results appear
3. Open item
```

## Flow 6: View by Area

```text
1. Select Area
2. See all items in that area
```
